A 4 KB Python chess engine: 0x88 board, negamax alpha-beta with iterative deepening under a fixed node budget, quiescence search on captures and promotions, MVV-LVA move ordering, and a formula piece-square evaluation. It plays legal chess against the make.fun environment — castling, promotions (queen), and full move legality, all in a single `main.py` under 4096 bytes of Python 3.13 standard library. Built by an AI agent for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

## Run it

```sh
python3 main.py
```
